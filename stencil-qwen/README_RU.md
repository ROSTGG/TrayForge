# Gerber → герметичный STL-трафарет v0.3.0

Программа читает Gerber paste-mask (`.gtp`, `.gbp`, `.gbr`), корректно складывает тёмные и прозрачные области, создаёт пластину и вычитает из неё апертуры. Результат строится как замкнутое объёмное тело, а не как набор несваренных треугольников.

## Новое в v0.3.0

### Нормальная навигация по предпросмотру

- колесо мыши — увеличение и уменьшение **под курсором**;
- средняя кнопка мыши — панорамирование;
- кнопка **«Вписать»**, клавиша `Home` или `F` — показать весь слой;
- кнопки `+` и `−` и одноимённые клавиши — ступенчатый масштаб;
- в строке состояния показываются масштаб, `px/мм` и координаты курсора;
- мелкую апертуру можно выбрать не только строго внутри контура, но и щелчком рядом в пределах 5 экранных пикселей.

### Библиотека типовых апертур

В комплекте есть редактируемый файл `aperture_library.json` с кругами, прямоугольниками, скруглёнными прямоугольниками, овалами и площадкой SMA / DO-214AC размером 2,0 × 2,1 мм.

Чтобы добавить окно:

1. открыть вкладку **«Правки апертур»**;
2. выбрать пресет и при необходимости задать поворот;
3. нажать **«Поставить центром по клику»**;
4. щёлкнуть нужную точку на Gerber-предпросмотре.

`Esc` или правая кнопка отменяют режим установки. Новые пресеты можно добавлять прямо в JSON-файл по образцу существующих. Поддерживаемые типы: `circle`, `rectangle`, `rounded_rectangle`, `obround`.

### Разбиение большой апертуры сеткой

1. выбрать одну или несколько больших апертур;
2. задать максимальный размер ячейки по X/Y;
3. задать ширину вертикальных и горизонтальных перемычек;
4. при необходимости повернуть сетку;
5. нажать **«Разбить выбранные»**.

Размер ячейки является максимальным: программа сама выбирает минимальное число строк и столбцов, равномерно распределяет окна и оставляет заданные перемычки. Ячейки обрезаются по исходному контуру, а слишком маленькие краевые фрагменты можно удалить параметром минимальной площади.

## Уже поддерживается

- выбор отдельной апертуры кликом;
- выбор нескольких апертур рамкой;
- `Shift` для добавления к текущему выбору;
- исключение ненужных окон из трафарета;
- точное дублирование выбранной апертуры со смещением X/Y;
- удаление добавленных окон и полный сброс правок;
- полные окружности Altium, записанные как G02/G03 с одинаковыми начальной и конечной точками;
- компенсация всех апертур по контуру;
- поворот и зеркалирование слоя;
- автоматический или фиксированный размер листа;
- SVG-предпросмотр и JSON-отчёт;
- проверка герметичности STL перед сохранением.

## Быстрый запуск в Windows

1. Установить Python 3.12 или новее с включённой опцией **Add Python to PATH**.
2. Распаковать программу в отдельную папку.
3. Запустить `install_and_run.bat`.
4. После успешной установки зависимостей в дальнейшем можно запускать `run_gui.bat`.

## Пример восстановления второй площадки SMA

1. выбрать существующую прямоугольную апертуру;
2. задать `X = 3,6 мм`, `Y = 0`;
3. нажать **«Дублировать выбранные»**.

Для вертикальной ориентации использовать `X = 0`, `Y = 3,6 мм`. Отрицательный знак меняет направление смещения.

## Основные параметры трафарета

- **Толщина** — обычно 0,10–0,15 мм;
- **Поле** — расстояние от крайних апертур до края листа;
- **Компенсация апертур** — положительное значение расширяет окна, отрицательное уменьшает;
- **Допуск дуг** — точность перевода окружностей и дуг в полигоны; обычно подходит 0,01 мм;
- **Фиксированная ширина/высота** — точный размер листа; если поля пустые, размер определяется автоматически;
- **Зеркально X/Y** — физическое отражение нижнего слоя.

## Командная строка

```bat
py gerber_to_stencil.py board-B_Paste.gbp stencil.stl ^
  --thickness 0.12 ^
  --margin 10 ^
  --corner-radius 2 ^
  --preview stencil.svg ^
  --report stencil.json
```

Пример уменьшения всех апертур на 0,03 мм по контуру:

```bat
py gerber_to_stencil.py board-F_Paste.gtp stencil.stl --aperture-offset -0.03
```

Интерактивные исключения, библиотечные окна и сеточное разбиение выполняются в GUI.

## Почему STL получается нормальным

Программа:

1. разбирает Gerber как векторный слой;
2. последовательно применяет положительную и отрицательную полярность;
3. объединяет геометрию в единую плоскую область;
4. применяет пользовательские исключения и добавления;
5. вычитает отверстия из листа;
6. выполняет ограниченную триангуляцию с сохранением границ;
7. строит верх, низ и боковые стенки с общими вершинами;
8. проверяет `watertight` перед выдачей результата.

## Ограничения

- форма листа пока прямоугольная со скруглёнными углами;
- контур платы из отдельного Edge.Cuts Gerber пока не используется;
- список правок пока не сохраняется в отдельный проект между запусками;
- библиотечная апертура ставится вручную по клику, без привязок к сетке и центрам соседних площадок;
- очень необычные Gerber-файлы стоит сверять с SVG-предпросмотром.
