# Gerber → STL-трафарет — описание приложения

## Что делает приложение

Программа превращает **Gerber-файл паяльной пасты** (`.gtp`, `.gbp`, `.gbr`) в **герметичный STL-трафарет** для 3D-печати или лазерной резки. Трафарет — это тонкая металлическая (или пластиковая) пластина с вырезами (апертурами) в тех местах платы, куда наносится паяльная паста.

Результат — замкнутое объёмное тело без «дырок» в сетке, готовое к слайсингу. Перед выдачей STL программа автоматически проверяет **watertight** (герметичность меша).

## Архитектура проекта

```
gerber_stencil_generator/
│
├── stencil_core.py          # Ядро — вся геометрическая логика (без UI)
├── stencil_gui.py           # Графический интерфейс (Tkinter)
├── gerber_to_stencil.py     # CLI-обёртка над stencil_core
│
├── aperture_library.json    # Библиотека типовых пресетов апертур
├── requirements.txt         # Зависимости Python
├── install_and_run.bat      # Установка зависимостей и первый запуск
└── run_gui.bat              # Быстрый запуск GUI
```

### Слои

| Слой | Файл | Роль |
|---|---|---|
| Ядро | `stencil_core.py` | Парсинг Gerber, булева геометрия, экструзия в STL |
| GUI | `stencil_gui.py` | Tkinter-приложение с предпросмотром, правками апертур |
| CLI | `gerber_to_stencil.py` | Командная строка, аргументы argparse |
| Данные | `aperture_library.json` | Редактируемый список пресетов форм |

## Зависимости

| Библиотека | Версия | Назначение |
|---|---|---|
| `gerbonara` | >=1.6, <2 | Парсинг Gerber RS-274X |
| `shapely` | >=2.1, <3 | 2D-геометрия, булевы операции, триангуляция |
| `trimesh` | >=4.0, <6 | Построение и валидация 3D-меша, экспорт STL |
| `numpy` | >=1.26, <3 | Числовые массивы для вершин и граней |

Стандартная библиотека: `tkinter`, `threading`, `queue`, `json`, `hashlib`, `math`, `dataclasses`, `pathlib`.

## Как работает конвейер (stencil_core.py)

```
Gerber-файл
    │
    ▼
load_gerber_image()          ← gerbonara парсит объекты/примитивы
    │  Каждый примитив → Shapely-полигон
    │  Тёмные (dark) области объединяются, прозрачные (clear) вычитаются
    │  Результат: одна 2D-геометрия (MultiPolygon)
    │
    ▼
list_openings()              ← разбиение на отдельные апертуры
    │  Каждой апертуре присваивается стабильный SHA-1 ключ
    │
    ▼  (GUI: пользователь выбирает / исключает / добавляет апертуры)
    │
exclude_openings_by_key()    ← удаление ненужных окон
add_openings()               ← добавление библиотечных / дублированных
split_opening_grid()         ← разбиение большой апертуры сеткой ячеек
    │
    ▼
build_sheet_and_material()   ← создание прямоугольного листа со скруглёнными углами
    │  Применяются: зеркало X/Y, поворот, компенсация апертур
    │  Лист минус апертуры = «материал» трафарета
    │
    ▼
extrude_material()           ← Shapely CDT-триангуляция + trimesh
    │  Верх + низ + боковые стенки строятся с общими вершинами
    │  merge_vertices + fix_normals + watertight-проверка
    │
    ▼
STL-файл  +  (опционально) SVG-предпросмотр  +  JSON-отчёт
```

### Ключевые классы и функции ядра

| Имя | Тип | Описание |
|---|---|---|
| `StencilOptions` | dataclass | Все параметры трафарета (толщина, поле, поворот, и др.) |
| `ConversionReport` | dataclass | Статистика результата (вершины, грани, герметичность, объём) |
| `StencilError` | Exception | Пользовательские ошибки конвертации |
| `load_gerber_image()` | функция | Парсинг Gerber → Shapely-геометрия |
| `list_openings()` | функция | Разбиение на апертуры с SHA-1 ключами |
| `opening_key()` | функция | Стабильный хеш одной апертуры |
| `exclude_openings_by_key()` | функция | Удаление выбранных апертур |
| `add_openings()` | функция | Объединение пользовательских добавлений |
| `create_library_aperture()` | функция | Создание апертуры из JSON-пресета |
| `split_opening_grid()` | функция | Разбиение апертуры сеткой с перемычками |
| `build_sheet_and_material()` | функция | Формирование листа и «материала» |
| `extrude_material()` | функция | 2D → 3D (CDT + trimesh) |
| `save_preview_svg()` | функция | Экспорт SVG-предпросмотра |
| `_rounded_rectangle()` | функция | Скруглённый прямоугольник / oval |
| `_full_circle_arc_to_geometry()` | функция | Полная окружность Altium (G02/G03 с совпадающими точками) |

## Параметры трафарета (StencilOptions)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `thickness_mm` | 0.12 | Толщина пластины |
| `margin_mm` | 10.0 | Отступ от крайних апертур до края листа |
| `corner_radius_mm` | 2.0 | Радиус скругления углов листа |
| `aperture_offset_mm` | 0.0 | Компенсация контура апертур (+ расширяет, − уменьшает) |
| `arc_tolerance_mm` | 0.01 | Точность аппроксимации дуг и окружностей |
| `sheet_width_mm` | None | Фиксированная ширина листа (авто если None) |
| `sheet_height_mm` | None | Фиксированная высота листа (авто если None) |
| `mirror_x` | False | Зеркалирование по оси X |
| `mirror_y` | False | Зеркалирование по оси Y |
| `rotate_deg` | 0.0 | Поворот всего слоя (градусы, против часовой) |
| `center_z` | False | Симметричное расположение по Z=0 |
| `min_opening_area_mm2` | 0.0 | Удалять апертуры меньше порогового значения |
| `precision_grid_mm` | 1e-6 | Шаг нормализации геометрии |

## Графический интерфейс (stencil_gui.py)

### Общий вид окна

```
+-----------------------------+------------------------------------------------+
|  Левая панель (controls)    |  Правая панель (предпросмотр)                  |
|                             |                                                |
|  [Gerber пасты] [Обзор…]   |  Предпросмотр апертур  [−][+][Вписать]        |
|  [Выходной STL] [Обзор…]   |                                                |
|                             |  +------------------------------------------+ |
|  +----------------------+   |  |                                          | |
|  |  Вкладка: Параметры  |   |  |   2D-отображение апертур (Canvas)        | |
|  |  Вкладка: Правки     |   |  |                                          | |
|  |        апертур       |   |  |   • серый фон (#15181c)                  | |
|  +----------------------+   |  |   • белые / голубые апертуры             | |
|                             |  |   • жёлтые — выбранные                   | |
|  [Лог-консоль (Text)]       |  |   • красные — исключённые                | |
|                             |  +------------------------------------------+ |
|  [Создать STL]              |                                                |
|                             |  Масштаб: 4.3x  |  12.3 px/мм  |  x=5.2 мм  |
+-----------------------------+------------------------------------------------+
```

### Левая панель — вкладка «Параметры»

Текстовые поля:
- Толщина, мм
- Поле вокруг апертур, мм
- Скругление углов, мм
- Компенсация апертур, мм
- Допуск дуг, мм
- Фиксированная ширина/высота листа, мм
- Поворот, °
- Мин. площадь апертуры, мм²

Чекбоксы: «Зеркально X», «Зеркально Y», «Толщина симметрично Z=0»

### Левая панель — вкладка «Правки апертур»

Разделы:

1. **Исключить / вернуть выбранные** — переключает видимость выбранных апертур в трафарете.

2. **Дублирование существующей апертуры** — копирует выбранные апертуры со смещением ΔX/ΔY (в мм).

3. **Библиотека типовых апертур** — выпадающий список пресетов из `aperture_library.json`. Кнопка «Поставить центром по клику» переводит курсор в режим размещения: следующий щелчок на предпросмотре ставит апертуру в эту точку. `Esc` или ПКМ отменяют режим.

4. **Разбиение выбранных апертур сеткой** — задаётся максимальный размер ячейки X/Y, ширина перемычек X/Y, угол поворота сетки, минимальная площадь краевых фрагментов.

5. **Удалить добавленные / Сбросить правки** — управление отменой изменений.

### Предпросмотр (Canvas)

| Цвет | Значение |
|---|---|
| Тёмно-серый фон `#15181c` | Фон холста |
| Белый | Обычная апертура |
| Жёлтый | Выбранная апертура |
| Красный / серый | Исключённая апертура |
| Голубой / бирюзовый | Добавленная (пользовательская) апертура |

Управление предпросмотром:

| Действие | Эффект |
|---|---|
| Колесо мыши | Масштаб под курсором |
| Средняя кнопка + тащить | Панорамирование |
| ЛКМ | Выбрать апертуру (или снять выбор) |
| ЛКМ + тащить | Рамочный выбор нескольких апертур |
| Shift + ЛКМ / рамка | Добавить к текущему выбору |
| Ctrl+A | Выбрать все |
| Home / F | Вписать весь слой |
| +/= | Увеличить масштаб |
| − | Уменьшить масштаб |
| Esc / ПКМ | Отменить режим размещения апертуры |

Строка состояния (внизу предпросмотра): текущий масштаб, px/мм, координаты курсора в мм.

## Командная строка (gerber_to_stencil.py)

```bat
py gerber_to_stencil.py <input.gbp> <output.stl> [параметры]
```

| Ключ | По умолчанию | Описание |
|---|---|---|
| `--thickness` | 0.12 | Толщина, мм |
| `--margin` | 10.0 | Поле, мм |
| `--corner-radius` | 2.0 | Радиус углов, мм |
| `--aperture-offset` | 0.0 | Компенсация апертур, мм |
| `--arc-tolerance` | 0.01 | Допуск дуг, мм |
| `--width` / `--height` | — | Фиксированные размеры листа |
| `--mirror-x` / `--mirror-y` | off | Зеркалирование |
| `--rotate` | 0.0 | Поворот, градусы |
| `--center-z` | off | Симметрия по Z |
| `--min-opening-area` | 0.0 | Мин. площадь апертуры, мм² |
| `--precision-grid` | 1e-6 | Шаг нормализации, мм |
| `--preview` | — | Сохранить SVG-предпросмотр |
| `--report` | — | Сохранить JSON-отчёт |

## Библиотека апертур (aperture_library.json)

Поддерживаемые типы форм:

| `shape` | Параметры | Описание |
|---|---|---|
| `circle` | `diameter` | Круг |
| `rectangle` | `width`, `height` | Прямоугольник |
| `rounded_rectangle` | `width`, `height`, `radius` | Скруглённый прямоугольник |
| `obround` / `oval` | `width`, `height` | Овал (обрезанный прямоугольник) |

Каждый пресет может иметь поле `rotation_deg`. Новые пресеты добавляются прямо в JSON-файл.

Поставляемые пресеты: 6 кругов (O0.5–2.0 мм), 6 прямоугольников (0.6×0.6 – SMA 2×2.1 мм), 3 скруглённых прямоугольника, 3 овала.

## JSON-отчёт (ConversionReport)

Сохраняется при `--report` или из GUI. Содержит:

| Поле | Тип | Описание |
|---|---|---|
| `input_file` | str | Путь к Gerber |
| `output_file` | str | Путь к STL |
| `primitive_count` | int | Число Gerber-примитивов |
| `opening_count` | int | Итоговое число апертур |
| `excluded_opening_count` | int | Исключено пользователем |
| `added_opening_count` | int | Добавлено пользователем |
| `opening_area_mm2` | float | Суммарная площадь апертур |
| `sheet_width_mm` | float | Ширина листа |
| `sheet_height_mm` | float | Высота листа |
| `thickness_mm` | float | Толщина |
| `vertex_count` | int | Вершин в меше |
| `face_count` | int | Граней в меше |
| `body_count` | int | Отдельных тел |
| `watertight` | bool | Герметичность меша |
| `volume_mm3` | float | Объём трафарета |
| `warnings` | list[str] | Предупреждения конвертации |

## Известные ограничения

- Форма листа только прямоугольная (со скруглёнными углами); контур из Edge.Cuts не поддерживается.
- Список правок не сохраняется между сеансами.
- Библиотечная апертура ставится вручную по клику без привязки к сетке или центрам соседних площадок.
- Интерактивные правки (исключения, добавления, разбиение сеткой) доступны только в GUI.
- Очень нестандартные Gerber-файлы рекомендуется проверять через SVG-предпросмотр.

## Запуск

```bat
# Первая установка:
install_and_run.bat

# Последующие запуски:
run_gui.bat

# Командная строка:
py gerber_to_stencil.py board-B_Paste.gbp stencil.stl --thickness 0.12 --preview stencil.svg
```

Требования: Python 3.12+, опция «Add Python to PATH» включена при установке.
