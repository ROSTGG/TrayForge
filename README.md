# TrayForge

Небольшое автономное приложение для создания параметрических лотков под электронные компоненты.

## Передача и запуск

Передайте архив `TrayForge-portable.zip`. После распаковки запустите `Запустить TrayForge.cmd` — приложение откроется в браузере и не требует установки или доступа к интернету.

1. Откройте `index.html` в браузере.
2. Выберите корпус из расширенной библиотеки (0201–1812, SOT, SOD, SMA/SMB/SMC, SOIC/TSSOP/QFN/LQFP/BGA) или укажите свой размер, сетку и параметры стенок.
3. Нажмите «Скачать STL» и сразу импортируйте файл в слайсер.

Перед серийной печатью напечатайте тестовую ячейку: зазор зависит от фактических допусков корпуса и вашего принтера.
